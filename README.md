# python-number-guessing-game
A simple number guessing game built using python.
About the project :
This is beginner friendly python project in which computer randomly selects a number between 1 and 100,
and player tries to guess it. 
The game provides hints to help the player guess the number correctly.
Technologies used:
1.Python 
2.Random module
Run the following command in your terminal:
python number_guessing_game.py
